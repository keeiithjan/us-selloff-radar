# EMA 五線交纏後快線跌破站回監控規格

## 目標

在日線市場資料中只找出 EMA 9／21／50／150／200 先交纏、近期形成多頭排列但乖離仍受控，且「前一日黑 K 實體跌破快線、隔日開盤重新站上 EMA9」的標的。單純持續擴張、已成熟或過度乖離的趨勢不得進入主清單。

## 無重繪定義

- 五條 EMA 使用日線收盤價與 `adjust=False` 計算。
- 開盤站回使用「當日開盤 > 前一個已完成交易日的 EMA9」。不得用尚未收盤當日的 EMA9，避免盤中重繪。
- 實體跌破發生在開盤站回的前一根日 K；黑 K 的開盤必須在該快線上方或相等、收盤必須在該快線下方。
- EMA9 與 EMA21 分別記錄；至少跌破其中一條才構成開盤站回訊號。

## 可計算條件

1. `spread_pct = (max(EMA9, EMA21, EMA50, EMA150, EMA200) - min(...)) / close * 100`。
2. 最近 60 根日 K（不含最新一根）內，至少一根 `spread_pct <= 3.0`，視為曾發生五線低乖離。
3. 最近一次低乖離距離最新日 K 不得超過 20 根，避免很久以前交纏過的成熟趨勢混入。
4. 最新一根滿足 `EMA9 > EMA21 > EMA50 > EMA150 > EMA200`，實際連續排列根數必須介於 3～15 根。
5. 最新五線總乖離 `spread_pct <= 6.0`，避免慢線已明顯落後的過度展開標的。
6. 與 5 根前比較，四組相鄰 EMA 距離中至少三組擴大，五線總 spread 亦擴大，且 EMA9 斜率為正。
7. 前一根必須為黑 K，實體由上往下穿越 EMA9 或 EMA21；最新一根開盤必須高於前一根已完成的 EMA9。缺少跌破或開盤站回任一條件即不輸出訊號。
8. 所有輸出訊號階段固定為 `open_reclaim`，再依目前五線乖離、壓縮距今根數與擴展分數排序。

## 輸出與監控

- 日線掃描沿用既有多市場資料下載，不重複呼叫行情來源。
- 訊號寫入 `data/sequential.json` 的日線 frame：`ema_ribbon_expansion`。
- 同步輸出 `data/KJ-EMA-Ribbon-Expansion.TXT`，供 TradingView 匯入。
- GitHub Actions 原有每 5 分鐘排程會自動執行；網站獨立面板只呈現完整通過交纏、受控乖離、快線跌破與開盤站回的訊號，並保留市場篩選與 TXT 下載。
