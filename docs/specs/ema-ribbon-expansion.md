# EMA 五線壓縮後多頭擴展監控規格

## 目標

在日線市場資料中找出 EMA 9／21／50／150／200 先收斂、再形成多頭排列並開始擴張的標的，並將「前一日黑 K 實體跌破快線、隔日開盤重新站上 EMA9」列為最高優先訊號。

## 無重繪定義

- 五條 EMA 使用日線收盤價與 `adjust=False` 計算。
- 開盤站回使用「當日開盤 > 前一個已完成交易日的 EMA9」。不得用尚未收盤當日的 EMA9，避免盤中重繪。
- 實體跌破發生在開盤站回的前一根日 K；黑 K 的開盤必須在該快線上方或相等、收盤必須在該快線下方。
- EMA9 與 EMA21 分別記錄；至少跌破其中一條才構成開盤站回訊號。

## 可計算條件

1. `spread_pct = (max(EMA9, EMA21, EMA50, EMA150, EMA200) - min(...)) / close * 100`。
2. 最近 60 根日 K（不含最新一根）內，至少一根 `spread_pct <= 3.0`，視為曾發生五線低乖離。
3. 最新一根滿足 `EMA9 > EMA21 > EMA50 > EMA150 > EMA200`，且這個排列至少連續 3 根。
4. 與 5 根前比較，四組相鄰 EMA 距離中至少三組擴大，五線總 spread 亦擴大，且 EMA9 斜率為正，視為正在多頭擴展。
5. 若前一根為黑 K，且實體由上往下穿越 EMA9 或 EMA21，而最新一根開盤高於前一根 EMA9，訊號階段為 `open_reclaim`；否則為 `expansion_watch`。
6. 排序先放 `open_reclaim`，再依擴展分數、壓縮程度排序。

## 輸出與監控

- 日線掃描沿用既有多市場資料下載，不重複呼叫行情來源。
- 訊號寫入 `data/sequential.json` 的日線 frame：`ema_ribbon_expansion`。
- 同步輸出 `data/KJ-EMA-Ribbon-Expansion.TXT`，供 TradingView 匯入。
- GitHub Actions 原有每 5 分鐘排程會自動執行；網站新增獨立面板、階段與市場篩選、TXT 下載。
