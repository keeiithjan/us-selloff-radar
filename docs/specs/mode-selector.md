# 首頁模式選擇器規格

## 目標

在長頁面頂端提供持續可見的模式選擇器，讓使用者不必反覆上下捲動，即可直接跳到指定監控模組。

## 行為

- 選擇器使用原生 `select`，在桌面與手機皆保持單列、可鍵盤操作。
- 導航列使用 `position: sticky` 固定於頁面頂端，並具備半透明背景與足夠層級，捲動後仍可操作。
- 提供六個模式：白線／橙線站回、大黑 K、EMA 交纏站回、全球期貨、週 K 白線收復、TD Sequential。
- 選項變更時平滑捲動至對應區塊；使用者偏好降低動態效果時改為立即跳轉。
- 手動捲動頁面時，選擇器同步顯示目前所在區塊。
- 每個目標區塊保留黏性導航列的頂部間距，避免標題被遮住。

## 相容性

- 不改變各監控模組的資料、篩選與匯出行為。
- 更新 PWA shell 版本，避免已安裝 App 繼續使用舊首頁與舊 JavaScript。
